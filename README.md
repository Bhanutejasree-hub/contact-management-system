# Contact Management System
## Project Overview

The Contact Management System is a web-based application developed using Python Flask and MySQL. It helps users manage contact information easily by allowing them to add, view, search, update, and delete contact details.

The application provides a simple and user-friendly interface built using HTML, CSS, Bootstrap, and JavaScript. It uses Flask for backend operations and MySQL for storing contact information.

## Live Demo

**Live Website:** https://contact-management-system.ethiodeploy.app/

## Technologies Used

- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Libraries:** MySQL Connector, Flask, Python-dotenv
- **Deployment:** EthioDeploy
- **Development Environment:** Visual Studio Code

## Features

- **Home Page:** Provides an overview of the application.
- **Add Contact:** Add new contacts with name, phone number, email, and address.
- **View Contacts:** Display all saved contact details.
- **Search Contacts:** Search for contacts using their names.
- **Edit Contact:** Update existing contact information.
- **Delete Contact:** Remove unwanted contact details.
- **Database Integration:** Store and manage contact information using MySQL.
